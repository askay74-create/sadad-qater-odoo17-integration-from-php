SADAD (Qatar) Payment Provider

Seamlessly integrate Qatar's leading payment gateway, SADAD Web Checkout, with your Odoo 17 Community Edition store. This module provides a complete, secure, and robust solution for accepting online payments.

🚀 Key Features

  • 💳 Secure redirect payment flow to SADAD's hosted page.
  • ⚙️ **Dynamic Settings Page**: Manage your Merchant ID, Test/Live Secrets, and Language without any code changes.
  • 🔐 **SHA-256 Signature Verification**: End-to-end security for requests, callbacks, and webhooks.
  • 🔄 **Reliable Notifications**: Support for both immediate browser callbacks and asynchronous server-to-server webhooks (IPN).
  • 📊 **Financial Reconciliation Wizard**: A powerful tool to match your Odoo transactions against SADAD's CSV statements, quickly identifying any discrepancies. Pro Feature
  • 🧪 **Developer-Friendly**: Includes a ready-to-use Postman collection for easy testing of all notification endpoints.

🔧 Easy Configuration

All credentials and settings are managed in a single, user-friendly screen within Odoo (**Website ‣ Configuration ‣ SADAD Settings**). Switch between Test and Production environments with a single click.

🔍 Powerful Reconciliation

Save hours of manual work with the built-in reconciliation tool. Simply upload your statement from the SADAD panel, and the wizard will automatically compare it with your Odoo records, providing a clear report of matched transactions, amount mismatches, and items missing from either system.
